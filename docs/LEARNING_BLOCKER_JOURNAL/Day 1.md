# Learning & Blocker Journal — Webhook Verification

## Day 1 — Initial Recon

### Objective

Learn webhook verification as an unfamiliar concept and build a small working prototype demonstrating how an application can receive and verify webhook requests.

### what I Understood
I learnt that a webhook allows one system to notify another system when an event occurs, rather than the receiving system repeatedly asking for updates.

I also learned that webhook verification is needed because an application should not automatically trust every incoming request. The receiving application needs a way to determine whether the request is legitimate.
